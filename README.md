## 📖 What Is GRAIN ROT?

**GRAIN ROT** is a horror co-op extraction builder set in a scorched wasteland where everything burns [citation:7]. Developed by **Beck & Branch Games** and published by **Neem**, the game was released on **August 7, 2026** on Steam and quickly earned **Very Positive** reviews [citation:2][citation:5].

You are a Living Spark surviving inside fragile wooden vessels that splinter, collapse, and catch fire. When your vessel breaks, the Spark escapes — death is just a change of scenery [citation:1][citation:7]. Ride a cursed elevator into shifting underground ruins with your crew, smash furniture for resources, and feed them into the Grinder for gold. If everyone breaks, your loot is lost [citation:1][citation:7].

The deeper you go, the worse the Rot becomes. Bodies warp, voices distort, and emotes become worse — or possibly better [citation:1]. Everything you haul back rebuilds your Outpost, unlocking interactive furniture, stat upgrades, rescued survivors, and stranger ways to survive the next descent [citation:5][citation:7].

## 🔧 How It Works

The trainer uses two methods to modify the game:

**WeMod Trainer** — external application that reads and modifies values in the game process's memory using standard Windows API calls [citation:3].

**Mod Menu Loader** — standalone executable that injects a DLL into the game process at startup, displaying an overlay similar to Steam or Discord overlays. The menu is toggled with `F1` [citation:6].

Both methods feature:
- **In-memory modifications** — reads and modifies values in real-time
- **No external dependencies** — runs entirely as a standalone .exe
- **Persistent toggles** — features stay active until turned off
- **No game file modifications** — all changes are applied in memory only

All modifications disappear when you close the tool. Your game files remain untouched [citation:6].
